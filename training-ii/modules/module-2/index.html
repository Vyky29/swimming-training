MODULE 2 — Guiding Learning Through Scaffolding

Aquatic learning does not develop through repetition alone.

This module explores how aquatic experiences, activities and aquatic skills are structured progressively through scaffolding, allowing instructors to individualise each swimmer's aquatic journey according to readiness, participation and aquatic development.

The clubSENsational Learning Principle emerges from this approach, guiding progression from stable isolated learning towards more integrated, coordinated and adaptable aquatic participation over time.

Block 1 — Understanding Scaffolding

This block introduces scaffolding as the structured process used to progressively organise, simplify and adapt learning.
Scaffolding allows instructors to control complexity, separate learning into manageable layers and progressively build towards more integrated aquatic participation over time.

    Block 2 — The clubSENsational Learning Principle

    This block introduces the structured progression model that underpins aquatic learning throughout the programme.

      Key Principle

      Aquatic learning becomes more stable and manageable when complexity increases progressively rather than immediately.

      Earlier learning layers create the stability that allows later coordination, movement and integrated aquatic participation to develop more successfully over time.
