# PixtoLearn swimming assets

Local copies of PixtoLearn flashcards and related pack images for clubSENsational training materials.

## `pack-1/`

Uploaded pack images renamed to `{id}.png` (IDs 161–240 from the source pack filenames).

Use these files when building Visual Schedules, First & Then activities, and other PixtoLearn-based UI.

See `pack-1-manifest.json` for the file list.

Already curated First & Then flasks also live in:

`module-5/first-then-flasks/`

## `pack-2/`

Folder 2 uploads (floating, streamlining & water safety and related sequences). Files named `{id}.png`; overview flyer saved as `overview.png`.

See `pack-2-manifest.json` for the file list.

## `pack-3/`

Folder 3 uploads (swimming strokes, diving, starts & turns and related sequences). Files named `{id}.png`; overview flyer saved as `overview.png`.

See `pack-3-manifest.json` for the file list.

## `pack-4/`

Folder 4 uploads (games, toys & equipment, extras). Source uploads used a `pack_5_*` filename prefix. Files named `{id}.png`; overview flyer saved as `overview.png`.

See `pack-4-manifest.json` for the file list.
